# Development workflow

Always use `/poteto-mode` for every development task in this repository, including planning, implementation, debugging, refactoring, testing, code review, and documentation changes.

Before starting development work, read and follow [Poteto Mode](.agents/skills/poteto-mode/SKILL.md). Apply it automatically, even when the user does not explicitly invoke `/poteto-mode`.

# Article voice

Never announce that an article takes an atheist perspective. Apply this rule to article bodies, titles, summaries, and other public editorial copy. Present the argument directly without labeling the writer's worldview.
